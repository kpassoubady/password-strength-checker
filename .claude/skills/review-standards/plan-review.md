# plan-review.md

## Plan Review Checklist

### Completeness
- [ ] All acceptance criteria have corresponding plan steps
- [ ] Approach is clearly stated (not "Option A or B")
- [ ] Root cause analysis is valid (for bug fixes)
- [ ] Steps are in correct dependency order

### Clarity
- [ ] Interface signatures are provided
- [ ] No obvious architectural issues
- [ ] Performance/memory considerations addressed
- [ ] Edge cases considered

### System Thinking
- [ ] Cross-project impacts identified
- [ ] Upstream/downstream dependencies noted
- [ ] Backward compatibility assessed
